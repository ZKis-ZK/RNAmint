How to install in Gmail:
1. Click inside the white box → Select All (Cmd+A) → Copy (Cmd+C)
2. Gmail → ⚙ → See all settings → Signature → create or edit a signature
3. Paste (Cmd+V) into the signature editor → Save Changes

Compatibility notes:
✅ Gmail (web & app) · Apple Mail · Outlook.com · Outlook for Mac · iOS Mail · Android Mail
✅ Table-based layout with inline styles — no CSS class reliance, no flexbox, no JavaScript
✅ LinkedIn icon: embedded PNG (base64) — renders in all clients, including Outlook for Windows
✅ Images wrap gracefully on narrow mobile screens (nowrap removed)
⚠️ WebP images: not supported in Outlook for Windows 2007–2019 (those users see broken images). If Outlook Windows recipients are important, the WebP files on rnamint.com can be re-exported as PNG.
